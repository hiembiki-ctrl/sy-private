# 지도 표면

## Decisions

- 지도는 MapLibre GL JS로 그린다. 멀리서는 돌릴 수 있는 지구본(globe 투영)으로 보이고, 확대하면 같은 지도에서 도시 규모의 선명한 상세 지도로 이어진다.
- 지도 타일과 스타일은 OpenFreeMap의 공개 인스턴스를 쓴다. API 키, 계정, 액세스 토큰이 필요 없다. 타일·스타일 주소는 한곳에서 정해 다른 제공처로 바꿀 수 있게 한다.
- 지도에는 OpenFreeMap, OpenMapTiles, OpenStreetMap 출처 표기가 항상 보인다.
- 클릭 가능한 도시 점과 이름표는 지원 도시에만 둔다. 지구본 뒷면에 있는 도시는 보이지 않고 클릭되지 않는다.
- 지도 하나를 화면 수명 동안 한 번만 초기화한다. 도시 선택, 일수 변경 같은 상태 변화로 지도를 다시 만들지 않는다.
- 지도를 불러오지 못해도 도시 목록과 일정 열람은 동작해야 한다.

## Boundaries

- 이동 동선 선과 장소 핀은 이 결정이 허용하는 범위가 아니다. 다음 사용자 결과에서 같은 지도 위에 얹는 방향으로 다룬다.
- 지도 위의 일반 control(확대 버튼, 도시 선택 보조 목록)과 일정 UI는 UI 구성 원칙을 따른다.
- 위성 사진 스타일은 이 결정에 포함되지 않는다.

## Why

사용자가 react-globe.gl 지구본을 확대하면 고정된 텍스처 해상도 때문에 선명도가 떨어질 것이라고 판단해 타일 기반 지도로 바꾸기로 했다. Mapbox는 위성 스타일이 가능하지만 계정과 토큰, 독점 약관, 월 5만 지도 로드 이후의 요금이 따른다. 사용자가 비용 부담 없는 대체제를 원했고, MapLibre GL JS는 Mapbox GL JS와 거의 같은 방식으로 지구본과 확대를 오픈소스 라이선스로 제공하며 OpenFreeMap은 키 없이 무료로 타일을 준다. 대신 지구본의 사실적인 위성 사진 느낌은 도로와 지명 중심의 벡터 지도로 바뀐다.

## Reconsider when

- OpenFreeMap이 중단되거나 차단되거나 속도가 사용하기 어려운 수준일 때(서비스 수준 보장이 없다)
- 위성 사진 스타일이 사용자 결과에 필요해질 때
- 확대 상태에서 탭 메모리나 성능이 사용하기 어려운 수준일 때

## Still-rejected alternatives

- Mapbox GL JS — 위성 스타일과 지구본이 가능하지만 계정, 공개 토큰 관리, 독점 약관, 월 5만 로드 이후의 비용이 따른다. 위성 스타일이 필요해지거나 비용 부담이 없어지면 다시 검토한다.
- react-globe.gl과 고정 지구 텍스처 — 텍스처 해상도가 확대 한계가 되어 상세 지도로 이어지지 않는다.
- React-Leaflet — 평면 2D 지도라 돌릴 수 있는 지구본이 사라진다. react-leaflet 5의 라이선스는 Hippocratic-2.1로 일반 오픈소스 라이선스가 아니다. 지구본이 필요 없어지면 다시 검토한다.
- CesiumJS — 번들과 메모리가 가장 커서 과하다.

## Evidence worth preserving

- 확인한 버전과 조건(2026-10): `maplibre-gl` 6.16.0, BSD-3-Clause, 피어 의존성 없음. 지구본 투영은 5.0(2025-01)부터 지원하며 스타일 로드 뒤 `setProjection`으로 켜고, 줌 10~12 사이에서 평면 지도로 이어진다. OpenFreeMap은 키·가입·요청 제한이 없고 상업 이용이 허용되며 기부로 운영된다. 큰 오프라인 내려받기는 제한된다.
- 문서로 확인하지 못한 것: 지구본 뒷면에서 마커가 자동으로 숨는지, 이 프로젝트의 Next.js 16과 React 19에서의 실제 동작, 확대 상태의 탭 메모리, OpenFreeMap 스타일 URL의 구체적 형태. 구현 때 확인한다.
- Mapbox GL JS 3.33.0은 독점 약관에 계정과 공개 토큰이 필요하고, 웹 지도는 월 5만 지도 로드까지 무료이며 WebGL 2가 필수다.
