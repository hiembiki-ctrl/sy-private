# 세션 복원 전에 연 로그인 창이 로그아웃 뒤 다시 열릴 수 있다

**Symptom**: 페이지를 열자마자 "로그인"을 눌러 입력창을 연 뒤 세션이 복원되면, 입력창은 사라지지만 이후 "로그아웃"을 누르면 입력창이 다시 열릴 수 있다.

**Observed evidence**: 코드 리뷰(low)가 `components/auth/auth-control.tsx`에서 지적했다. 입력창 표시를 `open && !email`로 계산하는데, `open`은 로그인·가입 제출 성공 때만 false가 된다. 실제 화면에서 재현하지는 않았다.

**Suspected cause**: 세션이 제출 경로가 아닌 곳(저장된 세션 복원, 다른 탭의 로그인)에서 생겼을 때 `open`이 true로 남는 것으로 의심된다.

**What was tried**: 일반 사용 경로(제출로 로그인)에서는 발생하지 않고 수용 기준도 깨지 않아 고치지 않았다.

**Proposed next step**: `email`이 생기면 `open`을 false로 맞추도록(예: 로그인 감지 시 닫기) 바꾸고, 세션 복원 뒤 로그아웃 시나리오를 테스트로 추가한다.
